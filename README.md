# Job Connect Hub

Build a complete full-stack web application called:

JOB PORTAL & RECRUITMENT SYSTEM

This is a college BCA project.

The application must be a real working application, not a static prototype.

TECHNOLOGY REQUIREMENTS

Frontend:

* ReactJS

* HTML5

* CSS3

* Bootstrap 5

* JavaScript

* Responsive design

* AJAX/fetch or equivalent API-based communication

Backend:

* Node.js

* Express.js

* REST APIs

Database:

* A real persistent relational database

* Use the platform's supported hosted database

* Use proper relational tables and foreign keys

Authentication:

* Registration

* Login

* Logout

* Secure password handling

* Role-based authentication

USER ROLES

1. JOB SEEKER

Features:

* Register

* Login

* Create profile

* Edit profile

* Add education

* Add skills

* Add experience

* Upload resume

* Search jobs

* Filter jobs

* View job details

* Apply for jobs

* View submitted applications

* Track application status

2. RECRUITER / COMPANY

Features:

* Register

* Login

* Create company profile

* Edit company profile

* Post job vacancies

* Edit jobs

* Delete jobs

* View posted jobs

* View applicants

* View applicant profiles

* View/download resumes

* Update application status

3. ADMIN

Features:

* Admin login

* Admin dashboard

* Manage users

* Manage recruiters

* Manage companies

* Manage job postings

* Manage applications

* Remove or deactivate inappropriate job postings

SECURITY

Implement:

* Secure authentication

* Role-based access

* Protected pages

* Protected database operations

* Input validation

* File upload validation

* Proper authorization

* Secure handling of secrets

IMPORTANT DEVELOPMENT RULES

Do NOT create a fake frontend with hard-coded data.

All important data must be stored in the database.

Forms must actually save data.

Login must actually authenticate users.

Job applications must actually be stored.

Recruiters must actually see applicants.

Application status changes must actually be stored and visible to job seekers.

Build this as a real full-stack application.

First analyze the requirements and create the application architecture, database structure and folder structure.

Then implement the application.
